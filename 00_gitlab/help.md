# Interaction with gitlab

## To upload a file for a Pylon volume

- go to https://gitlab.ub.uni-heidelberg.de/verlag/PapyrologicalPublicationPlatform
- then click on the folder epidoc: https://gitlab.ub.uni-heidelberg.de/verlag/PapyrologicalPublicationPlatform/-/tree/master/epidoc?ref_type=heads
- at the level .../epidoc click on the + sign and choose New file (it is important to be at the epidoc level)
- now type in Pylon_10_Petrella/petrella.xml (the first `slash` will be added when you hit save)
- the add the xml file into the empty box
