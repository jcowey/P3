# wordfile to XML

## Basic introduction to the process of preparing the wordfile before it is uploaded to P3-processing.

Once the word file has been vetted as is satisfactory for the editorial board and the author, make sure the following things are as complete as possible.

- All cited texts and bibliography have embedded links in the word file. Clean links make life much easier.
- Make sure that all cited bibliography has a corresponding biblio link in papyri.info
- Any embedded jpgs / images must be taken out of the word file. Anchors with the fig. numbers should be inserted in the file (this helps later for setting the figure XML in the P3-processed file)
